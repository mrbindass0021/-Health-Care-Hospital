# CarePlus Hospital Website
Static site: HTML, CSS, JavaScript, Bootstrap 5 and Font Awesome (loaded from CDN, so you need internet).

## Run in VS Code
1. Open VS Code > File > Open Folder > choose `careplus-hospital`.
2. Install the "Live Server" extension.
3. Right-click `index.html` > "Open with Live Server" (or just double-click index.html).

## Customize
- Hospital name: search for "CarePlus" in all files (Ctrl+Shift+F) and replace.
- Phone, email, address: `contact` section in the contact section of contact.html and index.html and the footer in `js/script.js`.
- Doctors, departments, services, facilities, reviews, blog posts: arrays at the top of `js/script.js`.
- Images: replace `images/hospital.jpg` (hero + about) and `images/doctors/doctor1-4.jpg` with your own photos using the same file names.
- Colors: variables at the top of `css/style.css`.
- Map: replace the iframe `src` in the contact section with your Google Maps "Embed a map" link.
- Emergency number: search for `112`.
